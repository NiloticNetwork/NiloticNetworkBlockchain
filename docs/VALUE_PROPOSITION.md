## Nilotic Network: Purpose-built blockchain for inclusive finance in Africa

### Problem
Millions of users and SMEs in East and wider Sub‑Saharan Africa face:
- Unreliable connectivity and high data costs
- Expensive cross‑border payments and FX spreads
- Cash‑dominant ecosystems with limited digital rails
- Low trust due to scams and opaque fees

### Solution (Why Nilotic is different)
Nilotic focuses on low‑bandwidth, offline‑first digital payments with transparent, programmable settlement:
- Offline/spotty connectivity support via Odero SLW token flows and delayed settlement
- USSD/SMS compatible agents and custodial lite‑wallets for feature phones
- Local stable settlement units with programmable FX corridors
- Micro‑transaction economics: sub‑cent fees, instant local acknowledgements, eventual on‑chain finality
- Simple, auditable open‑source core with small footprint (C++), easy to run on commodity hardware

### Core value for target customers
- Consumers: instant local payments that work without constant internet
- SMEs: cheaper settlement, programmable invoices, and cross‑border corridors
- Fintechs/Agents: easy integration (REST), revenue share via agent network
- NGOs/Programs: verifiable disbursements with offline redemption and auditability

### Initial beachhead use cases
1) School fees collection and micro‑savings groups (chamas)
2) Cross‑border micro‑remittances along Kenya–Uganda–South Sudan corridors
3) NGO cash‑transfer programs with offline redemption

### Why now
Connectivity is improving but still inconsistent; regulators increasingly supportive of sandbox pilots; demand for low‑fee, programmable rails is rising post‑mobile‑money maturity.

### Proof points we will build
- Pilot with 3–5 schools/SMEs; >1,000 wallets; <200 ms local ack; <$0.005 median fee
- Cross‑border corridor pilot with transparent FX and <2% total cost
- Third‑party security audit and public testnet metrics dashboard
