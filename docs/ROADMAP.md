## Nilotic Roadmap (12 months)

### Q1: Foundation + Pilot Readiness
- Public testnet launch with faucet and explorer
- Offline-first wallet flows (queued tx, local ack)
- Agent toolkit: USSD/SMS gateway adapter, REST SDKs
- Compliance: KYC tiers, basic AML heuristics, data retention policies
- Observability: metrics, logs, uptime, incident playbooks

### Q2: Pilot Executions
- School fees and chama pilots (3–5 institutions)
- Corridor pilot (KE–UG–SS) with FX oracle and capped spreads
- Security: 3rd-party audit booked; fuzzing + property tests
- API v1 freeze and OpenAPI; rate limiting and auth

### Q3: Scale and Partnerships
- Improve throughput and finality latency; WAL and migrations
- Agent network expansion; revenue share contracts
- Mobile SDKs and reference USSD app
- Compliance enhancements; regulatory sandbox applications

### Q4: Sustainability & Growth
- Token utility programs (fees, staking for agents, governance)
- Developer grants; ecosystem dApps for target use-cases
- Audit findings remediation and re-audit
- Regional expansion and BD for 10+ partners

### Milestone KPIs
- 10k monthly active wallets, <0.5% tx failure, <$0.005 median fee
- 10+ partners, 3+ corridor lanes, independent security audit completed
