## Team & Recruiting Plan

### Core Roles (founding)
- Protocol/Consensus Engineer (C++): validation, consensus, performance
- Wallet/Client Engineer (TypeScript/React Native): mobile + USSD integration
- Backend/Infra Engineer (Go or C++): APIs, metrics, reliability, DevOps
- Compliance/FinOps Lead: KYC/AML, corridor ops, partner onboarding

### Advisors
- Security (cryptography, audits)
- Regulatory (East Africa fintech and payments)
- BD/Partnerships (mobile money, NGOs, schools)

### Recruiting Plan
- Start with 3 founding engineers + 1 compliance lead
- Equity + mission alignment; hire from local tech communities
- Engage fellows/interns via universities and dev programs

### Hiring Signals
- Previous work on consensus, wallets, or payments infrastructure
- Ownership mindset, field empathy, low‑ego collaboration
